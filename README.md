# Cline Private

Приватное расширение VS Code. Агент ходит только на OpenAI-compatible сервер, который вы сами сохраняете. Адрес, ключ и список моделей задаёте вы. Фоновых запросов к Cline, каталогам моделей и телеметрии нет.

Первый запуск просит добавить подключение и нажать **Let's go!**.

## Подключение

Для каждого сервера сохраняются имя, base URL, API key, необязательные заголовки и id модели. Список моделей читается запросом `GET {baseUrl}/models`. Ключи лежат локально в `~/.cline/data/settings/providers.json`.

## Что остаётся в агенте

Файлы, терминал, браузер, checkpoints и правила проекта. MCP, который вы сами настроили, запускается только после подтверждения шага.

## Чего в этой сборке нет

Аккаунта Cline, подписки, облачных сессий, встроенных провайдеров и их каталогов, телеметрии, CLI, desktop-приложения и плагина JetBrains.

## Сборка

Нужны [Bun](https://bun.sh) 1.4.2 и Node.js 22 или новее.

```bash
bun install
bun run build:sdk
cd apps/vscode
bun run package
```

Расширение для установки лежит в `apps/vscode` после `bun run package`. Для разработки из исходников откройте эту папку как Extension Development Host:

```bash
code --extensionDevelopmentPath=apps/vscode
```
