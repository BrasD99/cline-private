# Cline Private

Автономный агент в VS Code. Запросы уходят только на OpenAI-compatible сервер, который вы сохранили: имя, base URL, API key и id модели. Список моделей берётся с `GET {baseUrl}/models`.

Агент правит файлы, запускает команды в терминале и может открыть браузер. Каждый такой шаг ждёт вашего подтверждения. Свой MCP подключается так же, после подтверждения.

В этой сборке нет аккаунта, каталога чужих моделей и телеметрии.
